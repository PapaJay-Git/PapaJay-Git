# Jayson Cainglet

Full stack engineer and technical lead. For the past two years I built **The Host Desk**, a short-term-rental operations SaaS, from its first commit into a production marketplace, and led the team behind it.

**Portfolio and writing → [cainglet.vercel.app](https://cainglet.vercel.app)** · source: [PapaJay-Git/portfolio](https://github.com/PapaJay-Git/portfolio)

### What I've built

- **[Rental-operations platform](https://cainglet.vercel.app/work/host-desk-platform)**: TypeScript and Express API with 218 Prisma models and ~523 endpoints, a React portal for six user roles, and a Stripe Connect work-order marketplace.
- **[SQL Server → PostgreSQL, solo](https://cainglet.vercel.app/work/postgres-migration)**: schema-driven export tooling and a verified cutover; major queries went from ~5 s to under 1 s.
- **[PMS data pipeline](https://cainglet.vercel.app/work/pms-data-pipeline)**: a Hostaway/Guesty mirror for an AI assistant, with a deduplicated job queue, advisory locks, self-healing webhooks and rate-limit budgeting.
- **[Zero-downtime deploys](https://cainglet.vercel.app/work/zero-downtime-deploys)**: blue-green releases with Docker, Nginx, health checks and automatic rollback.

That work lives in private company repositories; the case studies explain the decisions behind it.
